🛒 Tienda JS - E-commerce

Proyecto  desarrollado para el curso de Front-End JS de Talento Tech.

Tienda JS es una aplicación web de comercio electrónico (e-commerce) interactiva y moderna, diseñada para ofrecer una experiencia de usuario fluida y atractiva en la compra de productos tecnológicos.

🚀 Características Principales

Catálogo de Productos: Visualización dinámica de productos con opciones de filtrado y búsqueda.

Sección de Destacados: Muestra de los productos más populares o relevantes.

Reseñas de Usuarios: Espacio interactivo para opiniones y valoraciones.

Formulario de Contacto: Canal de comunicación directo con validación de datos.

Diseño Responsivo (Responsive Design): Adaptable a diferentes tamaños de pantalla (móviles, tablets y escritorio) mediante Flexbox y CSS moderno.

Interactividad con JavaScript: Lógica de cliente para mejorar la experiencia de navegación en tiempo real.

🛠️ Tecnologías Utilizadas

HTML5: Estructura semántica de las páginas web.

CSS3: Estilos avanzados, diseño flexible (Flexbox), variables CSS y diseño adaptable.

JavaScript (ES6+): Lógica de comportamiento, manipulación del DOM e interactividad.

Git & GitHub: Control de versiones y colaboración.

📂 Estructura del Proyecto

├── assets/          # Imágenes, íconos y recursos visuales
├── css/             # Archivos de estilos (style.css, variables.css, etc.)
├── js/              # Archivos de lógica y comportamiento en JavaScript
├── pages/           # Vistas secundarias (contacto.html, productos.html, etc.)
└── index.html       # Página principal de la tienda


💻 Instalación y Ejecución Local

Para visualizar y probar el proyecto en tu máquina local, sigue estos pasos:

Clona el repositorio:

git clone https://github.com/tu-usuario/tu-repositorio.git


Abre el proyecto:
Abre la carpeta del proyecto en tu editor de código favorito (por ejemplo, Visual Studio Code).

Ejecuta con Live Server:

Si usas VS Code, instala la extensión Live Server.

Haz clic derecho sobre el archivo index.html y selecciona "Open with Live Server".
